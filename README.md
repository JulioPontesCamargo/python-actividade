# Quer namorar comigo?

Um pedido de namoro interativo: o botão "Não" foge e o "Sim" só cresce.

- `index.html`: versão web, publicada com GitHub Pages.
- `main.py`: versão desktop em Python/tkinter (o projeto onde tudo começou).

## Rodando a versão Python

```bash
sudo apt install python3-tk   # Ubuntu/WSL
python3 main.py
```
